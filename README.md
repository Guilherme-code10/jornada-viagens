# ✈️ Jornada Viagens

Projeto de site responsivo desenvolvido durante a formação de **Front-end da Alura**, com foco em construção de interfaces adaptáveis para diferentes tamanhos de tela.

O projeto simula o site de uma agência de viagens e possui páginas de início, pacotes, blog e contato.

🌐 **GitHub Pages:** https://guilherme-code10.github.io/jornada-viagens/

## 🚀 Funcionalidades

- Página inicial com destaques e destinos
- Página de pacotes de viagem
- Blog de viagens
- Página de contato com formulário
- Menu de navegação responsivo
- Seções de ofertas e condições de pagamento
- Depoimentos de clientes
- Imagens adaptadas para mobile, tablet e desktop
- Layout responsivo com diferentes breakpoints
- Navegação entre múltiplas páginas

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Git
- GitHub
- GitHub Pages

## 📱 Responsividade

O layout foi desenvolvido seguindo uma abordagem responsiva, com adaptações para diferentes larguras de tela.

Entre os principais pontos trabalhados estão:

- navegação mobile;
- imagens específicas para diferentes dispositivos;
- reorganização do conteúdo;
- ajustes de tipografia e espaçamento;
- breakpoints para tablet e desktop.

## 🌎 Páginas

### Home
Apresenta os principais destinos, ofertas e informações da agência fictícia.

### Pacotes
Exibe destinos, condições de pagamento e depoimentos.

### Blog
Conteúdo relacionado a destinos e experiências de viagem.

### Contato
Formulário para o usuário enviar seus dados e mensagem, com layout responsivo.

## 🌿 Git e fluxo de desenvolvimento

Durante o desenvolvimento foram utilizadas branches específicas para diferentes funcionalidades e correções, como:

- `feat/hero`
- `feat/header`
- `feat/footer`
- `feat/categories`
- `feat/payments`
- `feat/contato`
- `bugfix/payments-gallery`

As alterações foram integradas à branch principal por meio de Pull Requests.
